# A Microcanonical Phase Transition for the Collatz Affine Random Model

**Yuan Si** (University of Waterloo)

Submitted to *Forum of Mathematics, Sigma*, 2026.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20027097.svg)](https://doi.org/10.5281/zenodo.20027097)

## Abstract

We study the Syracuse affine random model introduced by Tao (2022) and establish a sharp resonant phase transition at the entropy line. The microcanonical conditioning reduces the multiplicative phase to a deterministic Jacobi-theta cutoff profile, and the additive phase to a primitive ternary Bernoulli-bridge transform. Using a Bremont-type Rajchman argument and suffix self-similarity, we prove subexponential Fourier decay for frequencies growing as o(m/log m), yielding density-one convergence of orbits toward 1 along a fiberwise subsequence.
